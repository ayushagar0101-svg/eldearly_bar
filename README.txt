ASSETS FOLDER
=============

Place your files here using these exact names (already referenced in index.html):

- elderly-nutrition-bar.mp4   → the hero background video (muted, autoplay, loop)
- nutrition-bar.jpg           → fallback poster image shown before the video loads
- ingredients/                → optional folder for any ingredient photos you want to add later

The website works fine without these files present — the hero section will simply
show a dark background until the video is added. No code changes are needed;
just drop the files into this folder with the names above.
